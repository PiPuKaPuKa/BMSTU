## Часть 1. Операторы языка C++

### Цель работы

Овладеть навыками разработки программ на языке C++, реализующих циклические алгоритмы: цикл с предусловием (`while`), цикл с постусловием (`do-while`) и цикл `for`.

### Условие задачи

Сравнить скорость сходимости (число учитываемых элементов для достижения заданной точности ξ = 10⁻², 10⁻⁴, 10⁻⁶) при вычислении числа e с помощью ряда и бесконечной дроби:

e = 1 + 1 / (1 − 1 / (2 + 1 / (3 − 1 / (2 + 1 / (5 − ...)))))

Ряд: e = Σ 1/k! (k = 0, 1, 2, ...)

Точное значение e используется только для проверки и выводится после результатов.

### Текст программы

Файл `lab1/e_convergence.cpp`. Для ряда используется `do-while`, для дроби `while`, перебор точностей идёт в цикле `for`.

### Результаты

| ξ     | Ряд: слагаемых | Ряд: e       | Дробь: элементов | Дробь: e     |
|-------|----------------|--------------|------------------|--------------|
| 10⁻²  | 6              | 2.7166666667 | 6                | 2.7179487179 |
| 10⁻⁴  | 9              | 2.7182787698 | 8                | 2.7182835821 |
| 10⁻⁶  | 11             | 2.7182818011 | 10               | 2.7182818229 |

Точное значение: e = 2.7182818285.

### Выводы

Для всех трёх точностей бесконечная дробь требует на 0–1 элемент меньше, чем ряд. Для ξ = 10⁻⁶ дроби нужно 10 элементов, ряду 11 слагаемых. Оба способа дают результат с заданной точностью. Число элементов растёт с уменьшением ξ в обоих случаях.

## Тренировочная часть

### Структура Test

```cpp
struct Test
{
    short b;     // 2 байта
    int a;       // 4 байта
    char ch1, ch2;   // 1 + 1 байт
};
```

Печатает `sizeof(Test)` = 12.

Почему 12: компилятор выравнивает поля по их размеру. `short b` занимает байты 0–1, потом 2 байта пропуска, чтобы `int a` начинался с адреса 4. `int a` занимает байты 4–7, `ch1` и `ch2` идут в байты 8 и 9. Итого 10 байт, а размер структуры округляется до кратного 4 (выравнивание по `int`), то есть 12.

Переписанная структура, 8 байт:

```cpp
struct Test
{
    int a;           // 4 байта, байты 0–3
    short b;         // 2 байта, байты 4–5
    char ch1, ch2;   // 1 + 1 байт, байты 6–7
};
```

Проверено: `sizeof` = 8.

## Часть 2. Структуры и массивы языка C++

### Цель работы

Овладеть навыками разработки программ на языке C++, использующих структурные типы данных и динамические массивы.

### Условие задачи

Структура «Студент»: ФИО и массив структур «Дисциплина» (не менее 4 дисциплин; название и оценка). Группа хранится в `vector`, его размер вводится с клавиатуры.

Выполнить пункты 1–7, 9, 10 и 12:

1. Сколько студентов имеют неудовлетворительную оценку хотя бы по одному предмету.
2. Сколько студентов сдали все экзамены на 5.
3. Средний балл группы по заданной дисциплине.
4. Количество отличных оценок по всем предметам.
5. Сколько студентов имеют неудовлетворительную оценку по заданному предмету.
6. Сколько студентов имеют средний балл от 4 до 5.
7. Количество неудовлетворительных оценок по всем предметам.
9. Сколько студентов не имеют задолженностей.
10. Сколько студентов сдали сессию на 4 и 5.
12. Средний балл каждого студента.


### Результаты

Программа выполняет все перечисленные пункты. Пункт 12 выводится функцией `cout_middle_grades`.

### Выводы

Недостаток такого представления: название дисциплины записано у каждого студента отдельно. Опечатка в одном месте («Матан» вместо «Математический анализ») приводит к неверному результату, так как программа сравнивает строки.

Способы устранения: завести справочник дисциплин, у каждой дисциплины свой id, а в структуре студента хранить id дисциплины и оценку. Тогда название задаётся один раз и сравниваются числа, а не строки.
