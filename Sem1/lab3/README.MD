# Лабораторная работа 3, вариант 12 (C++)

Учебный проект: классы, перегрузка операций, наследование и полиморфизм.

## Что в папке

| Файл | Что это |
|------|---------|
| `part1_vector.cpp` | Часть 1: класс `Vector`, операция `*` (скалярное произведение) |
| `part2_shapes.cpp` | Часть 2: круг и эллипс, наследование и полиморфизм |
| `input.txt` | Входные данные для части 1 |
| `output.txt` | Результат части 1 (создаётся программой при запуске) |
| `README.md` | Этот файл |
| `.gitignore` | Список файлов, которые git не должен сохранять |

Каждая часть — отдельная программа со своим файлом.

## Как запустить

Часть 1 (результат записывается в `output.txt`):

```
g++ -std=c++11 part1_vector.cpp -o part1
./part1
```

Часть 2 (результат выводится в консоль):

```
g++ -std=c++11 part2_shapes.cpp -o part2
./part2
```

В CLion (Windows): открой нужный файл и нажми «Запуск». Файл `input.txt` должен лежать в той же папке, откуда запускается часть 1.

## Что делает программа

**Часть 1: класс `Vector`.** Вектор хранит числа в динамической памяти. Программа читает вектор и обычный массив из `input.txt`, считает скалярное произведение (`a * p`), затем показывает:
- обращение к элементам через `[]`;
- конструктор копирования (создаётся независимая копия);
- конструктор перемещения (данные переходят к новому объекту, старый становится пустым);
- присваивание с копированием и с перемещением.

Для примера из `input.txt`: (1, 2, 3) · (4, 5, 6) = 4 + 10 + 18 = **32**.

**Часть 2: круг и эллипс.** `Ellipse` наследует `Circle`. Показано:
- статический полиморфизм: функция выбирается по типу указателя;
- динамический полиморфизм: функция выбирается по типу объекта (`virtual`);
- вектор указателей на объекты обоих классов.

## Про git и README

**Git** — программа, которая запоминает историю изменений файлов. Можно вернуться к любой прошлой версии и увидеть, что и когда менялось.

**README.md** — первый файл, который видит человек, открывший проект. В нём пишут: что это, как запустить, что внутри. Формат Markdown: `#` — заголовок, `|` — таблица, тройные кавычки — блок кода.

Базовые команды git (выполняются в папке проекта, в терминале):

```
git init                    # начать отслеживать папку
git add .                   # добавить файлы в следующую запись
git commit -m "Лаба 3"      # сохранить запись с описанием
```

`.gitignore` говорит git, какие файлы не добавлять: собранные программы и результат `output.txt`.
