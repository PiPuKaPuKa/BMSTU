## Изучение функций и стандартных средств ввода-вывода в языке C++

### Цель работы

Овладеть навыками разработки программ на языке C++, использующих ввод-вывод в файлы.

### Условие задачи

Структура «Океанское судно» (поля: название, ФИО капитана, водоизмещение в тыс. тонн, численность экипажа). Создаётся массив (`vector`) судов размерности n. Он сохраняется в файл и читается из файла в текстовом или двоичном режиме.

Режимы приложения задаются параметрами командной строки:

```
write text ships.txt     — запись, текстовый режим
write binary ships.dat   — запись, двоичный режим
read text ships.txt      — чтение, текстовый режим
read binary ships.dat    — чтение, двоичный режим
```

### Текст программы

Файл `lab2_var12.cpp`. Запись и чтение одной структуры вынесены в функции `writeShip` и `readShip`. Режим (текстовый или двоичный) выбирается дополнительным параметром `bool bin`.

```cpp
struct Ship {
    string name;     // название
    string captain;  // ФИО капитана
    double tonnage;  // водоизмещение, тыс. тонн
    int crew;        // численность экипажа
};
```

В текстовом режиме каждая строка пишется с новой строки, числа через пробел. В двоичном режиме после строк записывается символ `'\0'` как признак конца, числа пишутся функцией `write` в машинном представлении.

### Результаты

Введённые данные (режим `write`):

| Название | Капитан | Водоизмещение, тыс. т | Экипаж |
|---|---|---|---|
| Titanic | Smith Edward John | 52.3 | 892 |
| Aurora | Ivanov Ivan Ivanovich | 10.5 | 120 |

Вывод данных, прочитанных из файла (режим `read`, одинаков для обоих режимов):

```
Titanic, Smith Edward John, 52.3 thous. t, 892 crew
Aurora, Ivanov Ivan Ivanovich, 10.5 thous. t, 120 crew
```

Размеры файлов:

| Режим | Размер |
|---|---|
| Текстовый | 75 байт |
| Двоичный | 83 байта |

### Выводы

Данные успешно записываются в файл и читаются из него в обоих режимах.

Двоичный файл оказался больше текстового на 8 байт. В двоичном режиме `int` всегда занимает 4 байта, а `double` 8 байт, независимо от значения. В текстовом режиме число занимает столько байт, сколько в нём символов: `52.3` — 4 байта, `892` — 3 байта. Строки в обоих режимах занимают одинаково (в текстовом после строки идёт `\n`, в двоичном `\0`).

Для коротких чисел текстовый файл получается меньше, для длинных (например, `123456789` или `3.14159265`) меньше будет двоичный. Зато двоичный формат читается быстрее (не нужно преобразовывать текст в число) и не теряет точность `double`.
